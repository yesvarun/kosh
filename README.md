# Kosh — dictionary everywhere + saved-word review

No build step, no API key, no cost.

## Which files actually matter

**Required — the app breaks without these:**
- `index.html`
- `manifest.json` (share sheet + installability)
- `sw.js` (offline app shell)
- `icon.svg`, `icon-maskable.svg`

**Optional:**
- `README.md` — notes for you only. The app never reads it. **Uploading it is not important**; skip it if you want.
- `build_dict.py` + `.github/workflows/build-dictionary.yml` — only needed if you want the offline dictionary.
- `dict/` — generated by the workflow, not written by hand.

## What it does
- **Lookup tab**: definitions, synonyms, pronunciation audio.
- **Share sheet**: install the PWA, then select text in any app -> Share -> Kosh.
- **Saved tab**: save words, tap to re-read later.
- **Review**: Leitner flashcards (boxes 1-5, 0/1/3/7/14-day intervals).

Lookups try three sources in order, stopping at the first hit:
1. **Offline dictionary** on the phone (instant, no data) — if installed
2. dictionaryapi.dev — has audio, but its word list is a small hobby dataset and misses ordinary words like *leave*
3. Wiktionary REST API — large and actively maintained

## Offline dictionary (optional, one-time setup)

Uses **WordNet** (Princeton) — ~150k headwords with definitions, examples, synonyms, part of speech. Chosen over Webster's 1913 (the other common free option) because 1913 English is full of archaic senses that are useless for studying modern vocabulary.

Setup, all from your phone:

1. Upload `build_dict.py` to the repo root.
2. Upload the workflow to `.github/workflows/build-dictionary.yml`. (In GitHub's web UI: **Add file -> Create new file**, then type the full path `.github/workflows/build-dictionary.yml` into the filename box — typing the slashes creates the folders.)
3. Repo -> **Actions** tab -> **Build offline dictionary** -> **Run workflow**.
4. It downloads WordNet, shards it into `dict/a.json ... dict/z.json` + `dict/index.json`, and commits them back to the repo. Takes a couple of minutes.
5. Open Kosh. The bar under the language selector now says how many words are available — tap **Download**.

After that, lookups hit the phone's own copy first and work with the network completely off. Tap **Remove** on the same bar to free the space.

**Why the workflow instead of just committing one big JSON:** GitHub's browser upload is capped at **25 MB per file**, and you have no terminal — so a hand-uploaded dictionary is a dead end. The Action does the download, generation and commit server-side, which sidesteps that entirely. The sharding also means a lookup only ever parses one letter's file, not the whole dictionary, which matters on a phone.

Storage: shards go into the **Cache Storage API**, not `localStorage` (which caps at ~5 MB and would be nowhere near enough).

## Local file (most common reason lookups show nothing)
Opening `index.html` straight from a file manager (`file:///...`) makes the browser block every network request. Kosh shows a red banner when it detects this. Always open the deployed `https://` link.

## Deploy (phone, no terminal)
- **Netlify Drop**: zip the required files, upload at app.netlify.com/drop. Note: Netlify Drop won't run the dictionary workflow — use GitHub if you want the offline copy.
- **GitHub Pages**: upload files at repo root -> Settings -> Pages -> deploy from `main` / root.

Share target needs HTTPS *and* the PWA to be installed (Add to Home Screen). Android/Chrome only — iOS Safari doesn't support Web Share Target.

WordNet is distributed under the Princeton WordNet license (free to use and redistribute with the copyright notice); `dict/index.json` records the source.
